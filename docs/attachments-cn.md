# 聊天附件

输入框旁的回形针支持选择多个文件，也可拖入文件或粘贴截图。

- 图片：PNG、JPEG、WebP、HEIC、HEIF；需选择已启用图片输入的模型，每条消息最多 3 张，每张不超过 10MB。
- 原文件：PDF、DOCX、XLSX、TXT、Markdown、CSV、TSV、JSON 和常见代码文件，每条消息最多 5 个，合计不超过 2MB。

文档不再由网页提取文字。原始文件字节编码为 data URL，作为 Responses API 的 `input_file` 连同问题发送到现有 OpenAI 兼容服务商，模型名称、服务商地址和认证设置沿用现有配置。扫描 PDF 也可选择，不要求网页 OCR。服务商需要支持 `/v1/responses` 和相应格式的文件输入；文件内部如何处理、能否理解图表，取决于服务商和模型。请求失败会显示错误，不会退回文字提取。

当前原文件模式仅接入 OpenAI 兼容服务商，暂不支持 Azure 或其他独立供应商适配器，也不支持同时使用插件。普通无文件对话仍使用原聊天接口。

原文件保存在浏览器聊天记录中，可以点击文件名下载，后续对话和重试也会保留文件。历史附件、图片、文字及 base64 编码后的完整请求不能超过 3.5MiB；超过会提示减少附件或新建对话，避免超过托管平台请求限制。自动标题和历史摘要仅处理对话文字，不向摘要模型重复发送原文件。尚未发送的附件不会在刷新后保留。

旧版聊天中已提取的文档文字仍可展开查看，不会自动转换为原文件。旧版 DOC、XLS 请先转换成 DOCX、XLSX。音频、视频、压缩包和 PowerPoint 暂不支持。

本次改动不更改设置存储名称、数据库或设置版本。在同一浏览器、同一固定网址使用时，已有个性化设置和聊天记录会继续保留。
