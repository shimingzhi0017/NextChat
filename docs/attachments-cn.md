# 聊天附件

输入框旁的“添加附件”支持选择多个文件，也可把文件拖到输入框或粘贴截图。

- 图片：PNG、JPEG、WebP、HEIC、HEIF；需选择已启用图片输入的模型，每条消息最多 3 张。
- 文档：PDF、DOCX、XLSX、TXT、Markdown、CSV、TSV、JSON 和常见代码文件，每条消息最多 5 个。
- 每个附件不超过 10MB。文档文字总计不超过 10 万字符，PDF 不超过 100 页，Excel 不超过 2 万个非空单元格。超过限制会提示拆分，不会静默截断。

文档在浏览器中解析。发送时，将提取的文字和问题一起交给现有聊天接口，无需另外配置文件上传 API。文件名会显示在聊天记录中，可以展开查看发送的文字，重试聊天时也会保留这些内容。

文档附件只包含提取的文字，不包含内嵌图片、图表、版式。PDF 中无法提取文字的页面会注明页码；完全没有文字的扫描版 PDF 会提示先做 OCR，或将需要分析的页面作为图片上传。加密、损坏、不支持的文件会显示错误。

旧版 DOC、XLS 请先转换成 DOCX、XLSX。音频、视频、压缩包和 PowerPoint 暂不支持。浏览器刷新前尚未发送的附件不会保留。

文档解析库按需加载；构建及导出命令会生成同源 PDF worker 文件 `public/pdf.worker.min.mjs`，无需连接外部 CDN。
